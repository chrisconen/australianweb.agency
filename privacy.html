Privacy · updated 17 October 2026

What we collect.
And what we don’t.

No cookies, no advertising trackers, no third-party analytics. Here is everything this site collects and why.

The details

Plain English.

Anonymous page counts

To see which pages and tools are useful, the site sends a counter to our own server when a page loads or when you use a marked link or tool. We store daily totals only: the page, the referring website’s domain, the country (from the network), the type of action and a short label. We do not store IP addresses, set cookies, fingerprint devices or create a visitor ID. If your browser sends Do Not Track or Global Privacy Control, nothing is sent.

The AI Agent Readiness Test

When you run the test, our server reads the public pages of the address you enter, the same way any visitor would. The report is cached for 24 hours so repeat tests are fast, and the test run is counted anonymously as above. The result is not linked to you.

Emails and calls

If you email us or book a call, we use your details to reply and, if we work together, to deliver the project and keep business records. We don’t sell or share them for marketing.

Services we use

The site is hosted on GitHub Pages, and the readiness test and page counters run on Cloudflare. Fonts are served from this site. These providers process technical data such as IP addresses to deliver their service, under their own privacy terms.
